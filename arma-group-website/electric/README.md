# ARMA Electric Company

Standalone site for ARMA Electric. Currently a single-page build — expand into this folder as you rework the site.

## Structure

```
electric/
├── index.html      ← Main page (edit this for now)
├── css/            ← Move styles here when splitting the file
├── js/             ← Scripts and config
├── images/         ← Logos, partner images, project photos
└── README.md
```

## Links

- **Back to ARMA Group:** `../group/index.html`
- **Linked from group homepage:** sector card → `../electric/index.html`

## Future work

When rebuilding (like Real Estate), add:

- `js/config.js` — hotline, WhatsApp, Messenger numbers
- `css/site.css` — shared styles
- Additional pages as needed (`projects.html`, etc.)

## Deploy

Can be deployed as its own Vercel project for a separate domain (e.g. `armaelectric.com`).
