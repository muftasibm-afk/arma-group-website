# ARMA Agriculture

Standalone site for ARMA Agriculture. **Next concern to rebuild after Real Estate.**

## Structure

```
agriculture/
├── index.html      ← Main page
├── css/            ← Split styles here during rebuild
├── js/            ← config.js, site.js when expanded
├── images/        ← Farm/site photography
└── README.md
```

## Links

- **Back to ARMA Group:** `../group/index.html`

## When you start the rebuild

Follow the same pattern as `../real-estate/`:

1. Add `js/config.js` for contact numbers
2. Add `css/site.css` for shared styles
3. Add `js/site.js` for loader, transitions, contact bubble
4. Replace `PLACEHOLDER_*` image paths with files in `images/`

## Deploy

Separate domain when ready (e.g. `armaagriculture.com`).
